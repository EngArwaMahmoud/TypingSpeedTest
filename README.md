Typing Speed Test

A simple C# project to measure typing speed.
It displays a paragraph for the user and counts down the remaining time using a Timer.

Features:

1-Countdown timer in seconds
2-Sound alert and message when time is up
3-Restriction on Arabic character input
4-Start and Stop buttons to control the test

Technologies Used:

1-Windows Forms
2-Timer Control
3-Event Handling
